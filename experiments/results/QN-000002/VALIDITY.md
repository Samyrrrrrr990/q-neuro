# Validity note

`QN-000002` completed successfully but is **preliminary and superseded** for cross-model claims.
The MLP received age and sex covariates while the Transformer and operator models received only
ordered findings. The chronology-twin result is unlikely to be caused by those covariates because
their distributions are identical within each twin pair, but the input asymmetry violates the
planned same-evidence control. The run is retained rather than deleted. A corrected replication
provides the same demographic context to every model.
