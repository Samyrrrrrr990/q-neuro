# Q-Neuro v0.1.0 — Foundational synthetic evidence

This release is a reproducible synthetic research milestone for hypothesis-state computing under
causal shift. It is not clinically validated and must not be used for diagnosis, triage, treatment,
or medical advice.

## Included

- Causal NeuroWorld tasks for chronology, missingness, composition, ambiguity, omitted labels,
  hidden syndromes, and active evidence acquisition.
- Conventional, real-operator, two-channel, complex-operator, dynamical, density-state, and
  adaptive-compute controls.
- Twenty-six registered studies, including a retained failed run, with versioned JSON summaries,
  paired analyses, a SQLite index, a claim ledger, and a failure inventory.
- Twenty publication figures, nine generated tables, an interactive static dashboard, and a
  54-page manuscript in Word, PDF, and modular LaTeX formats.
- Locked dependencies, CI, tests, linting, security guidance, citation metadata, a model card, and
  reproducible build targets.

## Evidence boundary

The recurring positive result is conditional: within the declared synthetic NeuroWorld shifts,
the tested complex operator is more robust than the finite comparison set, and retrained ablations
show contributions from ordered composition, phase-sensitive measurement, and observed-negative
evidence. The same study rejects a general-superiority story: the model is worse than a real
operator on irreducible ambiguity, source calibration fails to transfer, OOD separation is not
uniquely complex, hard halting degenerates to fixed truncation, and unconventional training laws do
not establish a new frontier.

Independent causal replication, stronger real-equivalent controls, larger top-level sample counts,
and governed external validation are required before stronger scientific or medical claims.
